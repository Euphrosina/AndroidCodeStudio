# Android Code Studio — v1.0.0+gh.r05（SDK 36 / 37 支持版）

## Overview

本次升级为 onboarding 安装器新增 **SDK 36.1.0 与 37.0.0** 选项（arm64 设备），并同步提供 arm64 的 35.0.1 自组包。同时将原 SHC 加壳的不透明安装器替换为**可审计的纯 shell 脚本**，下载全程增加 sha256 完整性校验。

## New Features

### SDK 36.1.0 / 37.0.0（arm64）
- Onboarding 的 Android SDK 版本清单新增 **36.1.0** 与 **37.0.0**（仅 arm64 设备可见）
- build-tools 35.0.1 / 36.1.0 / 37.0.0 的 arm64 包由 ACS 重新打包：
  - `aapt2` 采用 ReVanced 社区维护的 AOSP 主线静态编译版（NDK r27c，16KB ELF 对齐）
  - `d8` / `apksigner` 等组件来自 Google 官方 build-tools 包（平台无关 Java 组件）
- 安装 SDK 35/36/37 时**自动安装对应的 platform（android.jar）**：
  - 35.0.1 → platform-35_r02
  - 36.1.0 → platform-36_r02
  - 37.0.0 → platform-37.0_r02（自动创建 `android-37` 别名供 compileSdk 37 匹配）
  - 修复了此前「项目模板 compileSdk 36 但只能安装 build-tools 35」的错配问题

### 安装器透明化与校验
- 原 SHC 编译的黑盒安装器（二进制壳）替换为纯 bash 脚本（GPLv3，可审计）
- 所有下载（build-tools / platform / SDK base / platform-tools / cmdline-tools）均执行 **sha256 校验**，失败即中止，不落地损坏文件
- 34.0.4 及以下版本继续使用 AndroidIDE 官方社区包源

## Known Limitations
- SDK 36/37 目前仅提供 arm64 (aarch64) 包；armeabi-v7a 设备仍最高可选 35.0.1
- `--ndk` 参数暂跳过 NDK 安装（提示手动安装）；如需 NDK 28 支持请反馈
- aapt2 为 AOSP 主线编译（版本 2.19），非 Google 官方版本号；如遇与 AGP 的兼容性问题请回报构建日志

## Upgrade Notes
- 与 v1.0.0+gh.r04 同签名（ACS 修复版 keystore），**可直接覆盖安装**，无需卸载
- 已安装 SDK 35.0.1 的用户无需重装；36/37 为新增选项
